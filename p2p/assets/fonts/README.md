# Fontes

A interface atual usa os arquivos variáveis originais de Orbitron e JetBrains Mono, distribuídos sob a SIL Open Font License 1.1. As licenças completas acompanham cada família.

- Orbitron: https://github.com/google/fonts/tree/main/ofl/orbitron — `Orbitron[wght].ttf`, salvo como `orbitron-variable.ttf`; licença em `Orbitron-OFL.txt`.
- JetBrains Mono: https://github.com/google/fonts/tree/main/ofl/jetbrainsmono — `JetBrainsMono[wght].ttf`, salvo como `jetbrains-mono-variable.ttf`; licença em `JetBrainsMono-OFL.txt`.

Obtidos em 22 de outubro de 2026. Servidos pelo próprio projeto, sem consulta ao Google Fonts em tempo de execução.

`highlords-editorial.woff` e `LICENSE.txt` pertencem à revisão visual anterior e não são carregados pelo tema atual.
